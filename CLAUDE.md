# CLAUDE.md

## Before you start

- **Every agent:** read STATE.md (done, in progress, next, blockers) and PLAN.md (phases and tasks). Follow AGENT_RULES.md and CODEBASE_RULES.md.
- **Orchestrator (Fable role):** also read OPUS_HANDOVER.md first. Then read ROSTER.md, PROTOCOLS.md and DECISIONS.md.
- **External agent, new to the repo:** read EXTERNAL_BRIEFING.md first. If it and the repo disagree, the repo wins.
- UI work: follow DESIGN_RULES.md.

## When you finish

- Update STATE.md at each checkpoint. Log each new decision in DECISIONS.md.

## Linear

Keep the Linear project **TraceX** (team TIR) up to date with the work in this repo:

- When a task starts, set its issue to In Progress. When its PR merges, set it to Done and link the PR.
- Add an issue for new work. Cancel or remove issues that are no longer needed.
- Put each issue in the milestone for its phase (P0 to P6, as in PLAN.md).
- Update Linear at each STATE.md checkpoint.
